# Scrapline Real Asset Visual Authority Index

Purpose: GitHub-backed, real-source visual authority for the GPT-6.1 Sol one-shot build.

Synthetic image generation is explicitly excluded from this reference set.

This committed set is intentionally curated. The live workstation still contains a larger raw archive of individual staged renders, but Sol does **not** need that redundant evidence for the one-shot because the committed contact sheets and boards already consolidate it.

## Priority order

When visual sources disagree:

1. exact staged/contact-sheet evidence from the real approved UAssets,
2. live UEFN referenced-content captures,
3. real-asset composition studies,
4. local evidence/contact sheets,
5. official Fab pack media for broad context only.

Written authority still outranks visuals for coordinates, routes, gameplay geometry, spawn regions, verticality, and major-anchor transforms. See `docs/SPATIAL_CONTRACT.md`.

## Interpretation rules

### Factory hero crane

The Factory hero is a long horizontal industrial gantry/bridge assembly, not a tall skyline construction crane.

Preserve the shared-pivot relationship of the crane, cabin, and cable. Do not visually reinterpret it into a different crane archetype.

### Garage

The Garage is a compact workshop shell, not a district-sized warehouse. District identity must extend outward using approved service clutter, stairs, railings, workbench/shelf pieces, signs, Scrapyard grime, and surrounding cover.

### Scrapyard

The Scrapyard referenced-content board defines the rusted cross-district glue: wrecks, junk piles, metal catwalks, fencing, containers, towers/guardposts, reservoir/water-pump forms, and corrugated metal.

### VFX

Talisman dustmotes / sparks / steam are the default ambient language. Deserted fire/dust/storm systems are secondary spectacle only.

### Composition studies

The four composition studies use real approved assets and preserve realistic silhouette/scale, but their exact placement is exploratory.

Use them to understand:
- massing,
- silhouette relationships,
- clutter density,
- district identity,
- visual overlap between asset families.

Do **not** copy their coordinates as final layout. The spatial contract remains authoritative.

## Rule for future additions

Only add visuals with explicit provenance. Do not substitute generated lookalikes for real Scrapline assets.
